Politique de Confidentialité

MAYDAY — In-Store Repair Room Support Tool

Dernière mise à jour : 29 avril 2026

1. Responsable du traitement

MAYDAY est un outil de formation et de support interne développé pour les équipes Repair Room. Il est hébergé et exécuté localement sur les postes de travail des collaborateurs. Aucun serveur central ne collecte de données.

Contact : Équipe Repair Room

Hébergement : Exécution locale (file:// ou serveur HTTP local)

Nature : Outil interne de formation — usage exclusif en environnement professionnel

2. Données collectées et stockage

MAYDAY ne collecte aucune donnée personnelle (nom, email, identifiant). Les seules données stockées sont des préférences techniques, conservées dans le navigateur via localStorage.

3. Transferts de données hors UE

Le module Genius Bar Academy — Mode Live transmet un flux audio en temps réel vers les serveurs de Google LLC pour la simulation vocale IA.

Élément Détail
Données envoyées Flux audio microphone (PCM 16kHz)
Destinataire Google LLC — generativelanguage.googleapis.com
Localisation serveurs États-Unis
Finalité Simulation de formation interne (jeu de rôle client)
Base légale Consentement explicite (Art. 6.1.a RGPD)
Conservation Aucune — flux temps réel, non enregistré
Garanties EU-US Data Privacy Framework (DPF) — Google LLC est certifié
⚠️ Usage strictement limité : Le Mode Live ne doit jamais être utilisé lors d'interactions réelles avec des clients Apple sans leur consentement explicite et écrit.

4. Consentement et droits

Le Mode Live nécessite un consentement actif (opt-in via checkbox) avant toute activation. Ce consentement est :

  • Libre : l'utilisation de MAYDAY n'est pas conditionnée au Mode Live
  • Éclairé : les informations sur le destinataire et la finalité sont affichées
  • Spécifique : il ne concerne que le traitement audio
  • Révocable : vous pouvez retirer votre consentement à tout moment

Vos droits (RGPD Art. 15-22)

  • Droit d'accès : consultez vos données dans les paramètres de chaque module
  • Droit de rectification : modifiez vos préférences à tout moment
  • Droit à l'effacement : utilisez les boutons « Purger mes données » disponibles dans chaque module
  • Droit de retrait du consentement : désactivez le Mode Live à tout moment ; votre consentement expire automatiquement après 6 mois
  • Droit à la portabilité : exportez vos données via les fonctions d'export (CSV, JSON)

5. Comment supprimer vos données

Chaque module offre un mécanisme de suppression :

  • GeniusAcademy : Paramètres → « Réinitialiser Cache & Clé »
  • Mac Compagnon : Menu → « Purger les données locales »
  • EOD Close : Historique → « Effacer tout »
  • Global : Videz le localStorage de votre navigateur (DevTools → Application → Local Storage → Clear)

6. Cookies et trackers

MAYDAY n'utilise aucun cookie et aucun service de tracking tiers (pas de Google Analytics, Facebook Pixel, ou équivalent). Toutes les ressources (polices, icônes, styles) sont servies localement.

7. Sécurité

Les mesures de sécurité suivantes sont en place :

  • Les clés API sont stockées dans le navigateur uniquement, jamais transmises à un tiers (hors API Google autorisée)
  • Aucune donnée personnelle n'est collectée ni stockée
  • L'application fonctionne en mode local (file:// ou localhost)
  • Les entrées utilisateur sont échappées pour prévenir les attaques XSS

8. Modifications

Cette politique peut être mise à jour. La date de dernière modification est indiquée en haut de cette page. En cas de changement substantiel, une notification sera affichée dans l'application.
